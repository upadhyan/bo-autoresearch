## Question

What states does a **hypothesis** move through, what triggers each transition, and what does "accepted" mean?

The proposed states are proposed, registered (reject conditions frozen), active, rejected, retained and parked, and all of them are open to challenge. From 2608.00316, add a **narrowed** state, where the hypothesis is kept but its lever ranges shrink. Also decide whether a rejected hypothesis can ever be revived, for example when a newly added lever interacts with it. This is the anti-myopia guard.

- [LLINBO, 2505.14756](https://github.com/upadhyan/bo-autoresearch/blob/3ae38320b76012883d1d9cac974c52f1e733d5cb/docs/research/paper-2505.14756.md)

Neither has a hypothesis layer. Both support letting only mechanical evaluation decide verdicts, and Sara supports narrowing as a gated event.

**Gist:** hypotheses move through a small set of states. Only the harness's mechanical evaluation of the pre-registered conditions can reject or retain a hypothesis. Rejection is scoped to the levers it was tested with, and a rejected hypothesis can be revived as a new version when a new hypothesis might interact with it. Conflicts between hypotheses are caught at registration and resolved by a merge, by masking, or by recording the two as rivals.

### States
| State | Meaning |
|---|---|
| proposed | Drafted by the orchestrator. |
| pruned | Vetoed by a prohibited directive and never registered. It is re-reviewed only if that directive is revised. |
| registered | Reject conditions are frozen, and it is waiting for a slot. This state *is* the queue. |
| active | Its levers are in the current round's search space. |
| retained | The gates pass **and** the *lower* credible bound of the group total-order Sobol index is > τ. Whether the incumbent uses it is reported alongside. |
| rejected | A pre-registered reject condition fired. |
| inconclusive | Terminal only: still active when the research ended, with the gates never having passed. |
| parked | Withdrawn without a verdict, with a stated reason. It is never evidence against the hypothesis. |

The terminal states are retained, rejected, inconclusive, parked and pruned.

### Transitions and authority
1. **Verdicts are mechanical.** Only the harness assigns rejected or retained. Judges interpret the verdict and never override it. The orchestrator or the user can park a hypothesis at any time with a reason.
2. **Verdicts are recomputed every round.** A retained hypothesis can later be rejected, e.g. once a newly added lever explains its effect. Every transition is logged.
3. **A hypothesis whose gates haven't passed stays active**, still gathering trials. It does not become "inconclusive" round by round.
4. **Parked → registered** needs a stated reason and keeps the same version and reject conditions.
5. **Revival (the anti-myopia guard).** A rejection is scoped to the lever set it was tested against.
   - When a hypothesis registers, a subagent flags rejected hypotheses whose declared `mechanism` might interact with it.
   - Each flagged one re-enters as a **new linked version** with fresh reject conditions.
   - This happens at most once per (rejected hypothesis, new partner) pair.
   - While a lever is rejected it is frozen at its baseline value. How it maps into warm start is left to **Warm-start policy**.

### Events on an active hypothesis
- **Narrowing** shrinks lever ranges and keeps the hypothesis's identity and reject conditions (re-frozen on the new range).
  - It needs the importance gates to pass and a good surrogate fit.
  - It ends the round.
  - The round summary suggests it when the posterior mass is concentrated, because Sara found agents rarely narrow on their own.
  - Committed narrowing is the only kind. A temporary "probe" is just an agent-chosen trial.
- **Freezing** fixes a single lever at its baseline when that lever's own total-order upper bound is < τ. The hypothesis itself is not rejected.

### Unit of verdict
The unit is the whole hypothesis, judged on the group total-order Sobol index of its levers.

### Slots
- The orchestrator ranks registered hypotheses by priority, and a discouraged directive lowers priority.
- The harness enforces a cap on lever dimensions per round, derived from the trial budget, because rejecting needs ≥ max(10·d, floor) trials.
- A hypothesis left unselected for N rounds is flagged to the user rather than starved.

### Agent-chosen trials (from LLINBO)
- They count toward the objective.
- The **range-coverage gate counts sampler-chosen trials only**, because trials the agent picks tend to cluster.
- They are capped per round, and the cap shrinks each round, so the loop is never worse than plain Optuna.

### Conflicts between hypotheses (checked at registration, on revival, and on parked → registered)
1. **Harness check (hard block):** a config path belongs to exactly one live hypothesis. On a clash, the hypotheses must be **merged** into one whose range covers both, linked to the hypotheses it came from.
2. **Registration reviewer subagent** (the same one that checks directives): compares the new hypothesis's `mechanism` with every live one and classifies the pair as **shared-lever / exclusive / rival / none**. The orchestrator resolves what is flagged; the reviewer never merges.
3. **Exclusive, same slot and same shape** (BatchNorm vs LayerNorm): merge into one categorical lever, including a "none" option.
4. **Exclusive, different shapes** (mechanism X on/off vs regularisation Y's weight): use **masking** and keep separate hypotheses and verdicts.
   - An exclusion pair is declared with a precedence: a boolean masks a graded lever, and between two graded levers the orchestrator declares which masks which, with a reason.
   - When the masking mechanism is on, the harness runs the masked lever at its baseline value.
   - Each trial logs the masked lever's **sampled and effective** values, and the CSV has both columns.
   - The GP and Sobol use the *sampled* values, which keeps the box and independent inputs. The masking shows up as an X×Y interaction.
   - The masked hypothesis's gates count only trials where it was effective.
5. **Exclusive, and masking can't express it** (incompatible code paths): only one is active at a time, and the other waits in registered.
6. **Rivals** (competing explanations with separate levers) are allowed and encouraged. They are recorded as a `rival` link so the round summary reports which survived. Both being retained means both matter, not that one explains the other.

### Downstream notes
