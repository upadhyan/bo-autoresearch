## What to build
The single inlet for subagent output:
- `record <kind> --file`, where the kinds are proposal, review, interplay, narrative, expected and distill_spec. Each kind has its own JSON schema.
- A quote check: every number an output quotes from a verdict record must match that record exactly. Mismatches are refused with a reason.
- `check recorded <agent_id>`, which reports whether a valid record exists for that agent.

## Acceptance criteria
- [ ] A payload that fails its kind's schema is refused, with the failing field named.
- [ ] A narrative that misquotes √V_T, Δ or δ from a cited verdict record is refused. One that quotes them exactly is accepted.
- [ ] `check recorded` returns false until a valid record exists for that agent id, and true afterwards.
- [ ] Every accepted record is an event with its actor.
