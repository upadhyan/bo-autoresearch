## What to build
Conflicts caught at registration:
- A config path belongs to one live hypothesis. A clash forces a merge into one hypothesis whose range covers both, linked to the hypotheses it came from.
- Exclusive mechanisms with the same slot and shape merge into one categorical lever that includes a "none" option.
- Exclusive mechanisms with different shapes use masking with a declared precedence. The masked lever runs at its baseline when the masker is on. Each trial logs the sampled and effective values. The GP and Sobol use the sampled values. The masked hypothesis's gates count only trials where it was effective.
- Incompatible code paths are allowed only one at a time.
- Rival links, reported in the round summary.

## Acceptance criteria
- [ ] Registering a second hypothesis on a live config path is refused until the two are merged.
- [ ] A masked lever runs at its baseline whenever the masker is on, and both values are logged.
- [ ] The masked hypothesis's gates count only trials where it was effective.
- [ ] Rivals are both tested, and the verdicts of each are independent.
